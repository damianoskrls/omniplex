# BookUp Gym Admin

Web panel για τον ιδιοκτήτη γυμναστηρίου (πελάτες, υπηρεσίες, προσωπικό, διαθεσιμότητα, κρατήσεις, πακέτα).

## Τρέξιμο

1. Βεβαιώσου ότι τρέχει το API:
```bash
cd ../admin-api && npm start
```

2. Ξεκίνα το gym admin:
```bash
cd gym-admin
npm run dev
```

3. Άνοιξε: **http://localhost:5174**

## Τι μπορείς να κάνεις

- **Dashboard** — στατιστικά
- **Κρατήσεις** — προβολή ανά ημέρα, αλλαγή status
- **Πελάτες** — δημιουργία, προσθήκη πακέτων/πιστώσεων
- **Υπηρεσίες** — CRUD
- **Προσωπικό** — CRUD, ανάθεση υπηρεσιών, ωράριο διαθεσιμότητας
- **Πακέτα** — πλάνα τιμολόγησης
